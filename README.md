# Interactive Calculator & Unit Converter 🐍

## Project Overview
This project is a beginner-friendly Python command-line application developed as part of the InternCircle Python Programming Internship.

It performs basic arithmetic operations and unit conversions through an interactive menu.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Kilometres to Miles conversion
- Celsius to Fahrenheit conversion
- Kilograms to Pounds conversion
- Input validation using while loops
- Handles division by zero
- Interactive menu with Quit option

## Technologies Used
- Python 3
- Visual Studio Code

## How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

```bash
python calculator.py
```

## Unit Conversions
- 1 Kilometre = 0.621371 Miles
- Fahrenheit = (Celsius × 9/5) + 32
- 1 Kilogram = 2.20462 Pounds
